## 🛠️ Guide d'Installation (Android)

Puisque ces applications sont hébergées de manière indépendante (hors Google Play Store), vous devez autoriser l'installation à partir de sources inconnues.

1. **Téléchargez** le fichier `.apk` de votre choix depuis les liens ci-dessus.
2. **Ouvrez le fichier téléchargé** depuis vos notifications ou votre dossier *Téléchargements*.
3. Votre téléphone affichera peut-être un message de sécurité : *« Pour votre sécurité, votre téléphone n'est pas autorisé à installer des applications inconnues de cette source. »*
4. Cliquez sur **Paramètres** et activez **Autorisation depuis cette source**.
5. Revenez en arrière et appuyez sur **Installer**.
6. C'est fait ! L'application apparaîtra sur votre écran d'accueil.
